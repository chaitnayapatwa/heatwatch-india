# HeatWatch India — Digital Heatwave Risk Mapping

A polished HTML/CSS/JavaScript academic prototype for the topic:

**Digital Heatwave Risk Mapping for Indian Cities**

## Run in VS Code

1. Create a folder named `heatwave-risk-mapping`.
2. Put these three files inside it:
   - `index.html`
   - `style.css`
   - `script.js`
3. Open the folder in VS Code.
4. Open `index.html` with Live Server, or double-click the file.
5. No build step or npm installation is required.

## Main features

- Responsive landing page
- Interactive India-style risk map
- 24 illustrative Indian city records
- City search
- Risk-level filtering
- Indicator switching
- City detail panel
- City comparison table
- Risk sorting
- Methodology / composite index section
- Light/dark theme toggle
- City analysis modal
- Mobile responsive layout

## Important academic note

The values in `script.js` are **illustrative demo values** created for the interface. They are not official heatwave warnings or an official risk assessment.

For the final CA/report, replace the demo dataset with properly cited data from authoritative sources and document:
- source and year
- spatial scale
- units
- normalisation method
- indicator weights
- limitations

Suggested categories of sources to investigate:
- India Meteorological Department (IMD)
- Census of India / official population datasets
- government urban and disaster-management sources
- satellite/remote-sensing datasets
- peer-reviewed climate and heat-health studies

The project intentionally keeps the data layer separate in `script.js` so the UI can be reused with a real dataset later.
